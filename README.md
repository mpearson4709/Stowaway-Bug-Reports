# Stowaway — Bug Reports

This repo is for **reporting bugs in Stowaway and Stowaway Pro**, the scene
preset and workspace add-ons for Blender. It does not contain source code.

Get Stowaway: https://stowaway3d.com

## Reporting a bug

Open a [new issue](../../issues/new) and include:

- **Edition** — Stowaway (free) or Stowaway Pro
- **Blender version** (e.g. 5.2.1)
- **Stowaway version** (Edit > Preferences > Get Extensions, or the manifest
  version shown on install)
- **Steps to reproduce**
- **What you expected** vs. **what happened**
- Any error text from Blender's System Console (`Window > Toggle System
  Console` on Windows), if there was one

## Feature requests

Feature requests are welcome here too — just label them as such in the title.
